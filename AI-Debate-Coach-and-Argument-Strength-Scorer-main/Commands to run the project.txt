
Phase 1: First-Time Setup (Run once)
If you haven't installed the dependencies yet, open a terminal (PowerShell or Command Prompt) and run the following:

1. Install Backend Dependencies
Navigate to the server directory:
powershell
cd d:\Projects\project-master\debatable.-master\server

Activate the virtual environment:
powershell
.\venv\Scripts\activate

Install the required packages:
powershell
pip install -r requirements.txt

2. Install Frontend Dependencies
Open a new terminal window or deactivate the virtual environment (by typing deactivate), then navigate to the frontend root directory:
powershell
cd d:\Projects\project-master\debatable.-master

Install the Node.js packages:
powershell
npm install

Phase 2: Running the Project (Every time)
To run and test the application, you must start both the backend and frontend servers in separate terminal windows:

Terminal 1: Start the Backend

Open a terminal and navigate to the server directory:
powershell
cd d:\Projects\project-master\debatable.-master\server

Activate the virtual environment:
powershell
.\venv\Scripts\activate

Start the FastAPI server using uvicorn:
powershell
uvicorn main:app --reload --port 8000
(Keep this terminal open and running)

Terminal 2: Start the Frontend

Open a second, separate terminal window.
Navigate to the frontend root directory:
powershell
cd d:\Projects\project-master\debatable.-master
Start the React development server:

powershell
npm start
(Keep this terminal open and running)

Incase npm start didn't worked:
powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scop

Phase 3: Accessing the App
Once the frontend server starts, it will automatically open in your default browser at http://localhost:3000 (or you can open it manually).
The backend API will be running in the background at http://localhost:8000.
